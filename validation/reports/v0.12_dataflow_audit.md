## 每个物理参数的旅程

### energy / gamma / beta / p0
| 参数 | 定义 | 读取 | 转换/重新计算 |
|---|---|---|---|
| energy_keV | YAML `beam.energy_keV` | params.BeamParams, backend, ued_beamline_v2, tests | — |
| γ | 由 E 派生：`1.0+E_keV/511.0`，**在 12 处重新计算**（backend.py:258, beam_result.py:49, reference.py:23-24, ued_beamline_v2:90-91, run_shared:55-56, test_*）| — | 重复派生，值一致但**缺单一来源** |
| β | 由 γ 派生：`√(1-1/γ²)`，同样多处重复 | — | 同上 |
| p0 | 由 γβm_ec 派生，backend/AG 各自计算 | — | 值一致 |

### sigma_z / sigma_delta / sigma_delta_p
| 参数 | 定义 | 转换 | 备注 |
|---|---|---|---|
| sigma_delta | YAML `initial_distribution.sigma_delta`（**项目语义 = δ_p = Δp/p0**）| AG: 直接喂入（δ_p 语义）；OCELOT: `p_oc = β0·δ_p` 存入 rparticles[5] | **历史标签 "ΔE/E" 与语义不一致**（已在 R56 审计中确定为 δ_p），YAML 注释应更新 |
| sigma_delta_p | 输出语义 = std(p_oc)/β0 (OCELOT)；= state σ_δ (AG) | BeamResult.sigma_delta_e3 单位 ×10⁻³ | 语义统一 ✓ |
| sigma_z | YAML bunch_length_um→σ_tau=σ_z/β0 (OCELOT)；AG σ_z0 直接 | 输出 σ_z = β0·std(tau) (OCELOT) | ✓ |
| sigma_t | 输出 time_res_fs = σ_z/(β0c) (BeamResult) | — | ✓ |

### RF 参数
| 参数 | 定义 | 读取 | 转换 |
|---|---|---|---|
| 频率/电压/相位 | YAML `lattice.elements[rfi].parameters` | backend `_rf_constants(cfg,d,elem)`；ued_beamline_v2 `apply_rf_kick` 按实例读取 | k_rf=2πf/c 每实例计算 |
| kick | H=eV·k·cosφ/(β²E₀)；dδ_p=(V/(β²E_tot))·sin(φ+kz)；p_oc += β0·dδ_p | — | 公式固定 ✓ |
| 位置 | lattice z_start（唯一源）✓ | RFBODY=Drift(l)；kick 时机 z_start | v0.11 已消除硬编码 ✓ |

### Solenoid
| 参数 | 定义 | 转换 |
|---|---|---|
| B_field_T | YAML 元件 parameters | k_s = eB/(2p) 每实例计算（backend + ued_beamline_v2 + run_shared 三处各自实现，值一致）|
| 位置/长度 | lattice z_start/length ✓ | — |

### 其他
| 参数 | 状态 |
|---|---|
| beam charge | YAML → Q_C = fC·1e-15（backend/ued_beamline_v2 各一次）|
| particle number | YAML n_particles ✓ |
| random seed | 硬编码 `np.random.seed(42)`（backend.py、ued_beamline_v2.py、tests、benchmarks）——**未从配置读取，无单一声明点** |

## 关键发现（A/B 级）

1. **物理常数无单一来源**（A/B）：C_SI/M_E_SI/E_SI/511.0 在 ≥10 个文件重复定义（backend.py, reference.py, beam_result.py, params.py, ued_beamline_v2.py, run_shared.py, test_*）。
2. **γ/β/p0 无单一派生函数**（B）：12 处重复 `1.0+E/511`。
3. **random seed 非配置项**（B）：seed(42) 硬编码在多处，无 provenance 记录。
4. **OCELOT native 转换已隔离**（✓）：p_oc 只出现在 backend.py 的 run_ocelot/_ocelot_rf_kick 和 ued_beamline_v2.py 的 apply_rf_kick（两处都是 adapter 边界），未泄漏到 BeamResult/AG/plots。
5. **YAML 注释过时**（B）：`sigma_delta: relative energy spread ΔE/E` 与实际语义 δ_p 不符（R56 审计结论），仅注释问题，值不变。
