## 关键架构属性
1. **lattice.elements = 唯一几何真源**（v0.11 达成）：GPT 主路由、OCELOT 验证路由、AG region 构建全部从它读取。
2. **适配层边界明确**：p_oc = β0·δ_p 只在 backend.py 与 ued_beamline_v2.py 的 adapter 函数内出现。
3. **统一输出**：BeamResult 语义统一（σ_δ_p、ε_nx/ny 归一化）。
4. **可追踪**：meta 含 config_sha/switches/conversion_beta（v0.12 将补 git commit/timestamp/lattice hash）。
5. **已知结构债务**（记录不重构）：backend.py adapter+physics 混叠；主路由单体；`_section_regions` 与 run_ocelot 两套节段解释（已等价性验证）。
